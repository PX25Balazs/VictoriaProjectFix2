# Kanban Task Management Application

## Description
A Kanban-style task management application featuring a role-based model, priorities, deadlines, and a dashboard.

## Used techs
- C# / .NET 8 (ASP.NET Core MVC)
- PostgreSQL
- Entity Framework Core
- Docker & Docker Compose

## How to use
1. Download and set up Docker and Docker Compose.
2. Clone repository
3. In the project root, run the command:
   ```bash
   docker-compose up --build
